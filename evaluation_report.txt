🔍 METRICS INTERPRETATION GUIDE
--------------------------------------------------------------------------------
PRECISION (Accuracy): What % of extracted entities are correct?
  • 95% = System is very accurate when it identifies something

RECALL (Coverage): What % of actual entities did we find?
  • 80% = System finds 4 out of 5 entities that exist

F1 SCORE: Balanced measure of both precision and recall
  • 80%+ = Excellent performance
  • 60-79% = Good performance
  • <60% = Needs improvement

TP (True Positives): Correctly identified entities
FP (False Positives): Incorrectly identified entities
FN (False Negatives): Missed entities that should have been found
